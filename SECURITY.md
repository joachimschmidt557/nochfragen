# Security Policy

## Supported Versions

`nochfragen` does not have planned releases yet. The current state of the `trunk` branch is supported.

## Reporting a Vulnerability

Please write `security@josch557.de` with detailed information on the vulnerability, including a Proof-Of-Concept (PoC) for exploiting the vulnerability. If your vulnerability is accepted and patched, I will credit you (if you want to be credited).
